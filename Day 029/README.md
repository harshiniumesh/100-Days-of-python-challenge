# Day 029 - Password Manager GUI App

## Concepts Practised
* Building Multi-Field Forms with Tkinter (`Entry`, `Label`, `Button`)
* Grid Layout Management & Column Span (`columnspan`, `sticky`)
* Dialog Boxes & Confirmation Popups (`tkinter.messagebox`)
* Reading & Appending User Credentials to Local Files
* Clipboard Integration (`pyperclip`) for Instant Copying
